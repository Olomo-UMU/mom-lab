Equations and sign conventions

x is the mass displacement, positive downward, measured from static equilibrium. In equilibrium the spring is already stretched by δst = mg/k, so the spring force k·δst cancels the weight mg and gravity drops out of the equation of motion.

m ẍ + c ẋ + k x = F(t)   (force on mass)
m ẍ + c (ẋ − ẏ) + k (x − y) = 0   (support motion y)
ωn = √(k/m),  cc = 2√(km),  ζ = c / cc,  ωd = ωn√(1 − ζ²)

Free response from x₀, v₀

ζ < 1: x = e−ζωnt[x₀ cos ωdt + (v₀ + ζωnx₀)/ωd · sin ωdt]
ζ = 1: x = [x₀ + (v₀ + ωnx₀) t] e−ωnt
ζ > 1: x = A es₁t + B es₂t,  s₁,₂ = −ζωn ± ωn√(ζ² − 1)
Logarithmic decrement δ = ln(xi/xi+1) = 2πζ / √(1 − ζ²)

Steady state under F₀ sin ωt, with r = ω/ωn

X = (F₀/k) / √[(1 − r²)² + (2ζr)²],  tan φ = 2ζr / (1 − r²)

Steady state under support motion Y sin ωt (transmissibility)

X/Y = √[1 + (2ζr)²] / √[(1 − r²)² + (2ζr)²]

Isolation (X/Y < 1) needs r > √2. The total response is the steady state plus a free response chosen so that x(0) = x₀ and ẋ(0) = v₀. Velocity and acceleration are the exact time derivatives of x(t).

Energy about equilibrium

T = ½ m ẋ²,  V = ½ k (x − y)²

For an undamped system at exact resonance the steady state grows linearly: xp = −(F₀ / 2mωn) t cos ωnt.
